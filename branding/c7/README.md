# Seleção C7 LAB

A referência vigente é o catálogo oficial congelado fornecido pelo proprietário em 08/11/2026: 479 registros preservados e quatro adições em camada separada.

`selection.json` é gerado por `python3 tools/official_catalog/catalog.py --write`, nunca editado manualmente. Android e Roku recebem os mesmos bytes e SHA. Para verificar, execute o comando sem `--write`.

Fonte, backups, diferenças, testes e limites: `docs/lab/catalogo-unico-20261108/README.md`. O store e os relatórios da seleção C7 anterior são históricos; não importar playlists públicas nem reaplicar exclusões antigas sobre a nova fonte do proprietário. Somente o modo C7 LAB consome este asset.
